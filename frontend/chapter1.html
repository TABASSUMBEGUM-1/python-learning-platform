LESSON 01

What is Python?

Python is a programming language that lets us give instructions to a computer in a relatively simple and readable way.

THE IDEA

Think of Python as a way to talk to a computer.

We write instructions. Python interprets them. The computer performs the task.

Where can Python be used?

Build models and AI applications.

LESSON 04

Python Syntax

Syntax means the rules for writing code correctly.

THE IMPORTANT PART

Python uses indentation to define blocks.

This becomes especially important when we start writing conditions, loops and functions.

EXAMPLE

Indentation matters

Python
syntax.py Python 
if 10 > 5:
    print("10 is greater than 5")
OUTPUT
10 is greater than 5
